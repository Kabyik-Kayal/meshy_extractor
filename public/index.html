Cryptographic Authorization

Meshy encrypts `.glb` files into `.meshy` containers using WebAssembly. The decrypter requires an authorization signature computed via a 64-bit FNV-1a hash variant coupled with Murmur3 avalanche mixing.

instance.authorize("www.meshy.ai", timestamp, signature);

Full Resolution Reconstruction

Once authorized, the compiled WASM engine decrypts the container in memory. All vertices, normal maps, textures, and PBR materials are restored with 100% fidelity without downsampling or loss.

const glbBuffer = instance.processMeshyFile(encryptedBytes);

Command-Line Interface

Prefer the terminal or automated batch extraction pipelines? You can also run the built-in CLI directly via Node:

npm run cli https://www.meshy.ai/s/39mTE9 -o model.glb
